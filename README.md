# Каеф — сайт кафе (Казань)

Одностраничный сайт гастрокофейни «Каеф» (ул. Мансура Хасанова, 13). Next.js 14 (App Router) + TypeScript + Tailwind поверх CSS-токенов.
Дизайн: `DESIGN_SYSTEM.md`. Фото и права: `ASSETS.md`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3010
npm run build && npm start
npm run lint && npm run typecheck && npm test
```

Скопируйте `.env.example` в `.env` и при необходимости заполните переменные (все необязательные):

| Переменная | Что делает |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | домен сайта для OG, sitemap, canonical. Пока пусто, сайт считается демо и закрыт от индексации (noindex, robots Disallow) |
| `NEXT_PUBLIC_YM_ID` | номер счётчика Яндекс Метрики; пусто — аналитика не подключается вообще |
| `NEXT_PUBLIC_YANDEX_REVIEWS_WIDGET_URL` | адрес iframe официального виджета отзывов; пусто — показываются отобранные отзывы |

## Как менять контент

Весь контент — в одном файле [`src/data/cafe.ts`](src/data/cafe.ts). Компоненты текстов не содержат.

- **Меню:** массив `menu` (название, цена в рублях, ключ фото). Цену форматирует сайт. Блюдо без фото в меню добавлять не нужно.
- **Отзывы:** массив `reviews`. Только реальные отзывы, дословно, с автором и ссылкой на Яндекс Карты. Не сокращайте цитату так, чтобы менялся смысл.
- **Контакты, рейтинг, часы:** объект `cafe`. После изменения проверьте карточку в Яндекс Картах и обновите `checkedAt`.
- **Удобства и «Подходит для»:** `features`, `occasions`: только то, что подтверждено карточкой.

## Как добавить фото

1. Положите файл в `public/images/kaef/` (JPEG, длинная сторона до 2000 px, `npm run build` сам сделает AVIF/WebP).
2. Добавьте ключ в тип `PhotoKey` и запись в `photos` в `src/data/cafe.ts`: `src`, `width`, `height` (реальные размеры), `alt` по-русски.
3. Внесите строку в `ASSETS.md`: источник, автор, статус прав. Без подтверждённых прав фото использовать нельзя.

## Как подключить виджет отзывов Яндекса

1. В Яндекс Бизнесе / карточке организации: «Поделиться → Виджет с отзывами». Скопируйте адрес `src` из iframe.
2. Запишите его в `.env`: `NEXT_PUBLIC_YANDEX_REVIEWS_WIDGET_URL=https://yandex.ru/…`
3. Пересоберите сайт: `npm run build`. Секция «Отзывы» покажет iframe (ширина 300–760 px, высота 600 px, ленивая загрузка).

Принимаются только адреса `https://yandex.ru/…` и `https://yandex.com/…`. Внутренний дизайн виджета Яндекса изменить нельзя. Скрейпинг Яндекс Карт не используется.

## Яндекс Метрика

1. Создайте счётчик, запишите номер в `NEXT_PUBLIC_YM_ID`, пересоберите.
2. Появится баннер согласия. Метрика подключается только после «Согласен»; выбор хранится в `localStorage` (`kaef-consent`).
3. Без переменной баннера нет и никакие сторонние скрипты не грузятся.

## Что нужно от владельца перед публикацией

- Права на фото (оригиналы или письменное разрешение) — см. `ASSETS.md`.
- Реквизиты (ИП/ООО, ИНН) для футера и политики конфиденциальности: `legalLine` в `src/data/cafe.ts`.
- Подтвердить часы работы и актуальность меню и цен.
- Домен и хостинг: деплой в сборку не входит.
